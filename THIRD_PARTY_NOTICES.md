# Attribution and data notices

## Reference implementation

This project adapts geographic field processing, SoilGrids raster/WCS access patterns, disk-cache behavior and Copernicus terrain derivative formulas from **Tunen Challenge Solution — Madrid Open Vol. 1** by **Daniel Arias Suárez, Abraham Pozuelo Acedo, and Pablo Grano de Oro Sevillano**, copyright 2026.

The original MIT permission and copyright notice is preserved in `LICENSE-REFERENCE`. The original application directory was not modified to create this project. Recorded test fixtures were generated by querying public data sources during the source comparison, not by surveying real fields.

The interactive property-sheet stack is inspired by the reference project's `static/js/stack3d.js` interaction. This implementation uses Three.js, native-cell GeoJSON textures, and the validated field footprint.

## Map context

The local map outline/mask is derived from Natural Earth's public-domain 1:50m admin-0 countries dataset, simplified for display. Morocco and Western Sahara are grouped solely for the requested map extent; this display is not a determination of territorial status. Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson.

## Fertimap

Optional INRA / Moroccan Fertimap comparison is disabled. Public endpoint accessibility and the independent client's software licence do not establish a licence to redistribute Fertimap data. The operator must establish reuse conditions before enabling it. All-zero responses must be treated as missing; editable form estimates are not certified field measurements.
